# Constraints
These are rules applied to columns or tables.  They govern how data can be updated or inserted into a table.

There are several different types of Constraints:

- **[[Database/Terms/Not Null Constraint\|Not Null]]**
- **[[Database/Terms/Unique Key\|Unique]]**
- **[[Database/Terms/Primary Key\|Primary Key]]**
- **[[Database/Terms/Foreign Key\|Foreign Key]]**
- **[[Database/Terms/Check Constraint\|Check Constraint]]**
- **[[Database/Terms/Default Constraint\|Default Constraint]]**
