# Primary Key (Constraint)
A set of one or more [[Database/Terms/Attributes\|Attributes]], which cannot be null, that uniquely identify every [[Database/Terms/Tuple\|Tuple]] in a [[Database/Terms/Relation\|Relation]].

When implementing a Primary Key it is referred to a Primary Key [[Database/Terms/Constraints\|Constraint]].
